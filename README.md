# slidemaster

商品幻灯片母版合成库：将按顺序排列的 PNG 商品图与 WAV 背景音乐合成为无损 MOV
母版，供后续发布转码使用。媒体处理使用本机 FFmpeg，素材与结果均保存在本地目录。

## 环境要求

- Python ≥ 3.10，依赖 `numpy`、`Pillow`（测试需 `pytest`）
- 本机可执行 `ffmpeg` / `ffprobe`（需在 `PATH` 中）

## 输入约定

- 图片：按播放顺序排列的 PNG，不含透明通道，尺寸一致。
- 音乐：48 kHz、双声道、16 位 PCM 的 WAV。
- 时长：每张图的显示时长与每对相邻图的溶解时长，均为十进制秒
  （字符串、`int`、`Fraction` 均可精确解析；`float` 按其十进制表示解析）。

## 快速开始

```python
from slidemaster import compose

compose(
    images=["a.png", "b.png", "c.png"],      # 顺序即播放顺序
    durations=["2.5", "3", "1.75"],          # 每张图的显示时长（含入/出场转场）
    dissolves=["0.5", "0.25"],               # 相邻图之间的溶解时长，可为 "0"（硬切）
    music="bgm.wav",
    output="master.mov",
)
```

返回输出文件路径。可选参数 `work_dir=` 指定临时音频文件的存放目录
（默认使用系统临时目录，结束后自动清理）。

## 语义保证

- 帧率固定 30000/1001 fps，第 k 帧取样时刻为 `k * 1001 / 30000` 秒；只输出取样
  时刻严格早于整片逻辑终点的帧，最后一帧之后无黑帧或重复帧。
- 整片逻辑时长 = 显示时长之和 − 溶解时长之和；后一张图在前一张结束前的溶解
  时长处开始。所有归属与权重均由全局时刻判定，交界时刻属于从该时刻开始的新
  区间，任何时刻至多两张图参与混合。
- 溶解期间新图权重 = 经过时间 / 溶解时长，旧图取互补权重，在 8 位 RGB 上逐像素
  线性混合（四舍五入）；非转场画面保持原图像素。
- 全部时间用有理数精确累积，小数时长、不足一帧的转场、多次音乐循环均不会
  产生逐段漂移。
- 音乐从首个采样开始，短则首尾无缝循环、长则截断，不加静音或淡入淡出；音轨
  采样数 = `ceil(视频完整播放时长 × 48000)`，最后一个有效采样结束不早于视频
  结束，超出不足一个采样周期。
- 输出 MOV：视频为无损 QuickTime RLE（`qtrle`，`rgb24`），音频为
  `pcm_s16le` 48 kHz 立体声。

## 校验规则

- 溶解时长非负；每张图的入场 + 出场溶解时长之和不得超过其显示时长（允许恰好
  相等，即该图没有独占帧）；显示时长必须为正。
- 图片数量须与显示时长数量一致；所有图片尺寸一致且无透明通道。

## 运行测试

```bash
python3 -m pytest tests/ -q
```

覆盖：多段小数时长累积与不足一帧的转场（帧数与逐帧画面归属）、两个转场恰好
相接（中间图无独占帧）、零时长硬切（无空帧、无三图混合）、音乐循环/截断的
采样精确性。
