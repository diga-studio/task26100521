# slideshow_master — 商品幻灯片母版合成库

将多张 PNG 商品图与一段 WAV 音乐合成为无损 MOV 母版，供后续发布转码使用。
媒体处理使用本机 FFmpeg，时间编排全部以分数精确运算，保证与实际媒体一致。

## 环境要求

- Python 3.10+，依赖 `numpy`、`Pillow`
- 本机可用的 `ffmpeg` / `ffprobe`
- 运行测试需 `pytest`

## 输入约定

- 图片：按顺序排列的 PNG，不含透明通道，尺寸一致
- 音乐：48kHz、双声道、16 位 PCM 的 WAV
- 时长：十进制秒（`str` / `int` / `float` / `Decimal` / `Fraction` 均可，
  内部统一转为分数精确累积，不会逐段漂移）
  - `displays[i]`：第 i 张图的显示时长，包含它参与的入场与出场转场
  - `dissolves[i]`：第 i 张与第 i+1 张之间的溶解时长，可为零（硬切）
  - 每张图入场与出场溶解时长之和不得超过其显示时长（允许恰好相等，
    此时该图没有独占帧；任何时刻最多两个画面混合）

## 时间编排规则

- 帧率固定 30000/1001 fps，第 k 帧取样时刻为 `k*1001/30000` 秒
- 整片逻辑时长 = 显示时长之和 − 溶解时长之和
- 仅输出取样时刻严格早于逻辑终点的帧；交界时刻归属新区间
- 第一张从零时刻开始，第 i+1 张在第 i 张结束前的溶解时长处开始
- 溶解期间新图权重 = 经过时间 / 溶解时长，旧图取互补权重，
  在 8 位 RGB 通道上逐像素线性混合（整数精确计算，四舍五入）
- 最后一帧之后不附加黑帧或重复帧

## 输出

MOV 母版：视频 `qtrle`（QuickTime Animation，无损 RGB24），
音频 `pcm_s16le`（48kHz 立体声）。

音乐从首个采样开始，短则首尾连续循环，长则截断，不加静音或淡入淡出。
音轨采样数 = `ceil(帧数 * 1001/30000 * 48000)`，最后一个有效采样结束
不早于视频结束，超出不足一个采样周期。

## 使用方法

```python
from slideshow_master import compose

timeline = compose(
    images=["a.png", "b.png", "c.png"],   # 按顺序排列
    displays=["1.5", "2.0", "1.0"],        # 每张图显示时长（十进制秒）
    dissolves=["0.5", "0"],                # 相邻图溶解时长，0 为硬切
    music="bgm.wav",                       # 48kHz 立体声 16 位 PCM
    output="master.mov",
)
print(timeline.num_frames, timeline.audio_samples)
```

`compose` 返回 `Timeline`（各图起始时刻、整片逻辑时长、帧数、音轨采样数），
输入非法时抛出 `slideshow_master.ComposeError`。

## 运行测试

```bash
python3 -m pytest tests -v
```

覆盖场景：

- 多段小数时长累积并夹有不足一帧的转场：逐帧比对解码画面与参考实现
- 两个转场恰好相接（中间图无独占帧）与零时长硬切：无空帧、无三图混合
- 短音乐多次循环与长音乐截断：采样数精确、拼接无漂移、末尾覆盖视频终点
- 输入校验：透明通道、尺寸/数量不符、非法时长、非法音频格式
